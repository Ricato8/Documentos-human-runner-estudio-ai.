# C. Hunting & Business Opportunities

**Responsabilidad:** identificar, organizar y priorizar oportunidades comerciales, alianzas y conexiones estratégicas.
**Frecuencia:** semanal. **Agente:** `hunting`.

## Universo a mapear (foco inicial: Medellín / Antioquia → Colombia)
Clubes de running · grupos de entrenamiento · entrenadores · organizadores de carreras · eventos de ruta y trail · tiendas especializadas y distribuidores · marcas compatibles para colaboraciones · atletas y creadores de contenido · oportunidades de activación.

## Archivos
| Archivo | Uso |
|---|---|
| `prospectos.csv` | Base de datos de prospectos (una fila por organización/persona) |
| `eventos.csv` | Mapa y calendario de eventos |
| `fichas/` | Ficha de cada oportunidad priorizada (`plantillas/ficha-oportunidad.md`) |

## Priorización (puntaje 1–5 por criterio)
- **Afinidad** con HR (valores, estética, público).
- **Alcance** (tamaño de la comunidad o asistentes).
- **Potencial** comercial (B2C indirecto, B2B, contenido).
- **Facilidad** de concreción.

`puntaje = afinidad×0.35 + alcance×0.25 + potencial×0.25 + facilidad×0.15`. Prioridad A ≥ 4.0, B 3.0–3.9, C < 3.0.

## Estados del pipeline
`identificado → investigado → priorizado → aprobado_para_contacto → contactado → en_conversacion → propuesta → cerrado_ganado | cerrado_perdido | en_pausa`

## Reglas
- **Solo datos de contacto públicos y profesionales.** Nada de datos personales sensibles. Cumple la Ley 1581 de 2012 (habeas data).
- **El estudio no contacta a nadie** sin aprobación humana. Prepara mensajes y fichas; las personas envían.
- Las B2B se investigan y validan antes de presentarse como canal comercial (briefing §8).
- Cada registro lleva fuente y fecha de verificación.
